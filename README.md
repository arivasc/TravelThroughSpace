# 🌍 App de Realidad Aumentada: Explorando el Sistema Solar

[![Demo](https://media0.giphy.com/media/v1.Y2lkPTc5MGI3NjExMm54b2hwNGpudDl4eDIzdTZ1NnA4dW5rZ2RpZDU1bjEyNWQzNWpyOCZlcD12MV9pbnRlcm5hbF9naWZfYnlfaWQmY3Q9Zw/9hXCabBkhTmO98HBvq/giphy.gif)

> Una aplicación educativa en Realidad Aumentada (AR) donde, al escanear una imagen, se muestran en la pantalla **Mercurio, Venus y la Tierra** con sus respectivas descripciones.

---

## 🪐 ¿Qué hace esta app?

📸 Escanea una imagen física (Image Target)

🌌 Aparecen 3 planetas en 3D:
- **Mercurio**: El planeta más cercano al Sol, rocoso y lleno de cráteres.
- **Venus**: Similar en tamaño a la Tierra, pero con una atmósfera densa y caliente.
- **Tierra**: Nuestro hogar, el único planeta conocido con vida.

ℹ️ Cada planeta muestra una pequeña descripción junto a su modelo en pantalla.

## 🛠 Tecnologías utilizadas

- Unity 3D
- Vuforia Engine (AR)
- Android SDK
- Modelos 3D optimizados

---

## 🚀 ¿Cómo probarla?

1. Descarga el archivo APK o ejecuta el proyecto desde Unity.
2. Imprime la imagen objetivo (target).
3. Apunta la cámara del celular hacia la imagen.
4. Observa cómo aparecen **Mercurio**, **Venus** y **la Tierra** flotando en 3D.

---

## 🎯 Objetivo del proyecto

Fomentar el aprendizaje interactivo de los planetas más cercanos al Sol usando tecnologías de realidad aumentada. Ideal para estudiantes de primaria o secundaria.
